# 小c的心愿口袋

异地情侣的轻互动 PWA 应用。安卓浏览器打开，添加到桌面就是独立 App。

## 🚀 线上部署（Vercel）

- 平台：Vercel（静态部署，自带 HTTPS）
- 配置：`vercel.json`（关键文件 `sw.js` / `index.html` / `js` / `css` 设为不缓存，保证 PWA 更新即时生效）
- 更新方式：项目目录执行 `npx vercel deploy --prod --token=<你的token>`，同时把 `sw.js` 里 `CACHE_NAME` 版本号 +1

| 页面 | 功能 |

## 📱 怎么用（安卓手机）

### 1. 打开

用安卓手机浏览器（Chrome 推荐）访问应用地址。

### 2. 添加到桌面（变成 App）

- **Chrome**：浏览器菜单 →「添加到主屏幕」→ 桌面会出现「小c的心愿口袋」图标
- 点开就是全屏独立应用，没有浏览器地址栏，体验和原生 App 一样
- 支持离线打开（Service Worker 缓存）

### 3. 设置信息

首次打开会提示设置：
- **在一起的日子**——填后首页显示"已在一起 XX 天"
- **你的昵称 / 对方的昵称**
- 点首页头像可以**上传自定义头像**（会自动裁剪压缩）

## 🔄 双人同步

当前版本数据存在本地（localStorage）。双人云端同步方案已预留接口（`store.js` 的 `syncData` / `mergeData`），配对码机制设计好了。

要启用云端同步，需要：
1. 部署一个云端数据库（推荐 Supabase 免费版）
2. 在 `store.js` 里把 `SYNC_ENABLED` 改为 `true`，填入端点
3. 两人用同一个配对码连接

这部分我可以帮你一步步搭建。

## 🔧 后续怎么加功能不丢数据

这是重点设计。`store.js` 里有 `migrateData()` 函数和 `SCHEMA_VERSION` 机制：

1. **加新字段**：在 `defaultData()` 里加新字段，旧数据会自动补齐
2. **改结构**：`SCHEMA_VERSION` +1，在 `migrateData()` 里写迁移逻辑
3. 更新代码后，用户刷新页面，数据自动迁移，不会丢

### 加新的许愿卡 / 心情选项 / 纪念日预设

改 `js/config.js` 对应数组即可。

### 加新页面

在 `js/app.js` 里加 `Pages.xxx = { render() {...} }`，在 `index.html` 的 tabbar 加一个 `<div class="tab" data-tab="xxx">`。

## 💡 设计要点

- **无打卡压力**：没有连续天数、没有任务清单、不量化付出
- **PWA 架构**：不用应用商店审核，刷新即更新
- **数据迁移机制**：`schemaVersion` + `migrateData()` 确保后续加字段不破坏旧数据
- **头像自动压缩**：上传时裁剪为 120×120 并压缩到 JPEG 80%，节省存储
- **照片压缩**：瞬间照片上传时压缩到 800px 宽 / JPEG 75%
